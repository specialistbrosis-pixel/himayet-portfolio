03 / ENGINEERING METHOD

Make the process
as strong as the idea.

The discipline I want to bring to every future project: make the question clear, record assumptions, test carefully, and be honest about the evidence.

01

Observe

Understand the real problem, users, operating context, and constraints before choosing a solution.

OUTPUT · PROBLEM STATEMENT
02

Model

Break the system into components. Sketch the mechanism, map energy or signals, and state assumptions.

OUTPUT · SYSTEM MODEL
03

Prototype

Build the simplest suitable test version, prioritising safe methods and a clear reason for each design choice.

OUTPUT · WORKING CONCEPT
04

Measure & improve

Record test conditions, compare results with expectations, explain limitations, and decide what to change next.

OUTPUT · TEST RECORD

This is the process standard I am developing for future work; it is not a claim that every past project has a complete engineering test dossier.
